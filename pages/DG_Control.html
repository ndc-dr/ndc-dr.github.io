Strict Operational Guidelines
RULE 1: Mains Normal When utility power grid is normal, 3 sets of D.G.s stay at rest (Standby). ATS connected to Utility mains side. TIE ACBs open. LiFePO4 floating.
RULE 2: Grid Failure When grid fails, D.G. 1 & 3 start in parallel. Meanwhile, SmartLi LiFePO4 batteries instantly supply loads (0ms). When DGs stabilize, ATS transfers, and TIE ACBs on MDBs close.
RULE 3: Swing Failover If D.G. 1 or D.G. 3 fails to start, D.G. 2 (Backup Swing) automatically starts to replace the failed unit via 2DGSB, maintaining redundant power.
RULE 4: Grid Restoration When grid recovers, TIE ACBs on each side of MDB turn off, ATS transfers back to utility mains, and DGs continue running in cooldown before auto-stopping.
RULE 5: Manual Override Allows manual operation of bus switches, TIE ACBs, breaker positions, and manual DG starts for maintenance or testing windows.
